# Danh mục hồ sơ trình thẩm định BCKTKT

1. Văn bản đề nghị thẩm định (Mẫu số 04).
2. Văn bản pháp lý (chủ trương, quy hoạch, đất đai...).
3. Hồ sơ khảo sát, thuyết minh, thiết kế bản vẽ thi công, dự toán.
4. Hồ sơ năng lực nhà thầu tư vấn.
5. Tài liệu đặc thù (PCCC, môi trường, ITS...).
